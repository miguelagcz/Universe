# Universe

Proyecto web desarrollado con **Next.js**, enfocado en crear una experiencia moderna y responsive. Forma parte de mi portafolio como proyecto para practicar arquitectura, componentes y desarrollo frontend con el ecosistema React.

## ✨ Características

- Aplicación web con Next.js.
- Arquitectura basada en componentes.
- Diseño responsive.
- Optimización y estructura moderna de frontend.
- Preparado para desarrollo y despliegue web.

## 🛠️ Tecnologías

- Next.js
- React
- TypeScript
- CSS

## 🚀 Instalación

```bash
git clone https://github.com/miguelagcz/Universe.git
cd Universe
npm install
npm run dev
```

Después, abre `http://localhost:3000` en el navegador.
