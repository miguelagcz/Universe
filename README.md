# Universe — Interactive 3D Web Experience

Experimento web desarrollado con Next.js, React y Three.js para explorar experiencias visuales tridimensionales en el navegador. El proyecto combina el ecosistema moderno de React con herramientas de renderizado 3D e interacción gráfica.

## Enfoque del proyecto

- Desarrollo de una experiencia web visual con Next.js.
- Integración del ecosistema React Three Fiber para renderizado 3D.
- Uso de componentes y utilidades de Drei.
- Exploración de efectos gráficos con herramientas de postprocesado.
- Estructura con TypeScript y herramientas actuales de frontend.
- Integración de analítica de Vercel en el stack del proyecto.

## Tecnologías

- Next.js 16
- React 19
- TypeScript
- Three.js
- React Three Fiber
- Drei
- React Three Postprocessing
- Tailwind CSS 4
- Vercel Analytics

## Requisitos

- Node.js compatible con la versión de Next.js utilizada.
- npm.

## Instalación

```bash
git clone https://github.com/miguelagcz/Universe.git
cd Universe
npm install
npm run dev
```

Abre http://localhost:3000 para visualizar el proyecto en desarrollo.

## Comandos disponibles

```bash
npm run dev    # servidor local
npm run build  # compilación de producción
npm run start  # servidor de producción
npm run lint   # revisión estática
```

## Qué demuestra

Exploración de interfaces web más allá del contenido tradicional: componentes React, TypeScript, integración de librerías 3D y organización de una aplicación moderna. El comportamiento final depende de la implementación presente en el código fuente.
